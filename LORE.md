# The Lore Web

This is the index. Every file in `lore/` is reachable from here. Files cross-link via `[[name]]` — when you see a link to a file that doesn't exist yet, that's a prompt, not an error.

## Conventions

- **Frontmatter** on every file: `type` (entity / concept / thread / artifact), `status` (canon / draft / open-question), short `description`.
- **Canon** = locked, don't undo without a reason. **Draft** = working. **Open-question** = deliberately unresolved; the mystery lives here. Don't accidentally close these.
- **Tone:** a real field agent wrote it. Bureaucratic-but-warm, technical-but-mystical. No winks at the reader.
