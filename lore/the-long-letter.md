# The Long Letter

There is, somewhere in [[hq]]'s archives, a single document that every agent across the Department's history has contributed to. Not a logbook. Not a manual. A *letter*.

It is undated as a whole, though individual entries are dated. It has no recipient on the envelope. The earliest legible fragment, transcribed from a clay tablet, reads (in translation): *"You will not have heard from us in a while. We are still here. We are still listening."*

It continues. Across millennia. In hundreds of languages. Always the same letter.

## Why we don't know what it's for

We've asked. The archive doesn't say. The oldest agents we can find in the records don't say. Even HQ memos that reference it reference it as if everyone already knows.

The most common theory among field agents: it's a letter being written to whoever, or whatever, started [[the-department]] — the first being who heard the [[resonance-grid|Grid]] and decided to listen on purpose. The agency has been writing back to that first listener ever since. The letter is what we have to say for ourselves.

The most common theory among HQ paperwork-side: it's a letter being written to whoever comes after.

The Pleiades office has its own theory which it does not share.

## How agents contribute

Most agents never see it. Some get sent fragments to read. Once in a while an agent receives a request — formal, slightly creased, with no return address — asking them to write a single line. Refusing is fine. Most don't refuse.

## Connection to Seven

The earliest entries are unsigned. The next-earliest are signed with the seven-dot Pleiades constellation. See [[seven]]. See [[who-is-seven]]. Field agents have noticed. Field agents have not pressed.

## Open questions

- Who is it to.
- Who started it.
- Whether it ever ends.
- Whether the line you add stays the line you wrote.

Don't resolve. The Long Letter works because it is still being written.
