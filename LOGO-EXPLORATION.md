# D.I.V. Logo — Exploration Sheet

A wide spread of directions for the D.I.V. logo. **Pick none, pick many, mash combinations.** Each direction has a vibe, real-world references you can google for visual mood, and a starter prompt you can paste into Midjourney / ChatGPT image / Sora / etc.

The brand fundamentals these all share:
- Name: **Department of Intergalactic Vibrations** / acronym **D.I.V.**
- Palette: deep cosmic purple, iridescent silver, hi-vis striping, black
- Motif: the **Pleiades** (Seven Sisters star cluster)
- Tagline candidates: *"Maintaining the Resonance Grid since 12,847 BCE"* · *"In Resonance We Trust"* · *"Pleiades Field Office"*
- Anti: not New Age, not crystals-and-mandalas, not modern startup chrome

## How to use this sheet

1. **Pick 3-5 directions** that pull at you. Ignore the rest.
2. **Run the prompts** through your tool of choice (Midjourney v6 / Sora / ChatGPT image / Figma AI). Generate several variations of each.
3. **Mash directions.** "Apollo patch but with Wes Wilson lettering." "OSHA signage with the Pleiades motif." Combinations are usually stronger than pure picks.
4. **Bring the favorites back** and we'll narrow.

### Notes for prompt iteration
- Swap "Pleiades cluster" for "seven stars" or "Subaru cluster" if results get too literal.
- Add "no people, no faces" if the AI keeps adding astronauts.
- Add "vector, flat, no photorealism" if you want clean graphics.
- Add "embroidered patch, thread texture" if you want patch-ready output.
- Try the brand statement *"In Resonance We Trust"* as a tagline in the lower arc.
